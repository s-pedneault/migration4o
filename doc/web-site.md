# Web site plan

The public web site for this project is in `web/public/migration/`.

It is a single-page web site.

## General design

- One pager
- Modern, adaptive
- Animated
- In French only (for now)

## Contents

1. List of compatible third-party software
    1. Columns:
        1. Software name
        1. Vendor name
        1. Status (available, in development, planning)
        1. Modules offered
        1. Pricing
        1. Data import capabilities
        1. Compatibility with Migration4o
2. Contact button for visitors to notify us of more compatible software
3. Information about our product Migration4o, inspired from `admin/Brochure sans prix.doc`

The list of compatibile software should start with our own M4o app. We will add other products later.
