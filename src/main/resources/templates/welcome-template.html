Utilisation

Utilisez le menu de gauche pour naviguer entre les modules et les classes exportées. Cliquez sur une classe pour ouvrir son tableau de données interactif. La barre de recherche du menu filtre les classes par nom.

Recherche avancée par critères

Chaque tableau dispose d'un panneau de recherche structuré. Cliquez sur + Critère pour ajouter une condition, puis choisissez :

  • Le champ — utilisez le filtre texte intégré pour restreindre la liste, ou laissez sur Tous les champs pour chercher partout.
  • L'opérateur — six options disponibles selon le type de champ :
    Contient Ne contient pas Égale Différent de Est vide N'est pas vide
    Les deux derniers n'ont pas besoin de valeur.
  • La valeur — saisir du texte, puis appuyer sur Entrée ou cliquer Appliquer.

Logique ET / OU

Dès qu'il y a deux critères ou plus, un badge grisé affiche la logique active (ET ou OU). Cliquer dessus bascule entre les deux modes pour l'ensemble des critères simultanément.

Colonnes visibles

Le bouton Colonnes (en haut du tableau) ouvre un sélecteur permettant d'afficher ou de masquer les colonnes de votre choix. Lorsqu'un critère de recherche porte sur un champ masqué, ce champ est automatiquement rendu visible.

Pagination

Le sélecteur Rangées ajuste le nombre d'enregistrements affichés par page. Les boutons de navigation permettent de parcourir les pages de résultats.

Fiche détail & bouton XML

Cliquer sur une ligne ouvre la fiche complète de l'enregistrement dans un panneau latéral. En haut de la fiche, le bouton XML ouvre le fichier XML source de la classe dans un nouvel onglet — utile pour inspecter la structure complète ou copier les données brutes. Les flèches ◂ ▸ permettent de naviguer d'une fiche à l'autre sans fermer le panneau.
