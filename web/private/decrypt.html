M4E1 file format details 
Header (12 bytes):
  [4 bytes]  Magic "M4E1"
  [4 bytes]  Chunk size (uint32 BE) — plaintext bytes per chunk
  [4 bytes]  Total chunks (uint32 BE)

Per chunk:
  [12 bytes] IV (random, unique per chunk)
  [4 bytes]  Ciphertext length (uint32 BE, includes 16-byte GCM tag)
  [N bytes]  Ciphertext (AES-256-GCM)

Algorithm: AES-256-GCM
Key: 256-bit, provided as Base64 (44 chars)
